# README tour and screenshots

The README GIF is captured from the actual local build with Playwright. It shows
the wool atlas, searching the brand directory for Fox Brothers, the company
research page, and switching weave structures in the science lab. It does not
use generated interface imagery or external media. The GIF reflects repository
content, which can be ahead of the hosted deployment.

The capture uses a fresh browser context with no saved user data. The encoded
GIF is 1,024 × 704 pixels, uses a shared 192-color palette, and loops with long
holds on reading scenes. The static poster is available beside the GIF link in
the README for readers who prefer no motion. A GIF itself cannot honor reduced
motion settings or offer a pause control on every Markdown renderer.

## Reproduce the media

Media tools are optional; Python and Pillow are not needed to build or use the
site, or to run its normal checks.

```sh
npm ci
npm run build
npx playwright install chromium
python3 -m venv work/tour-venv
work/tour-venv/bin/python -m pip install Pillow==12.3.0
TOUR_PYTHON=work/tour-venv/bin/python npm run docs:tour
```

To use installed Chrome, prefix the last command with `BROWSER_CHANNEL=chrome`.
`BROWSER_EXECUTABLE` can select another Chromium executable. `TOUR_PORT` changes
the local preview port from its default of 4182. The command starts and stops its
own preview server and browser. It never deploys, publishes, or schedules work.

`scripts/capture-tour.mjs` records the screenshots and a frame manifest in the
ignored `work/readme-tour/` directory. `scripts/encode-tour.py` uses Pillow to
resize those frames and encode the GIF. The capture fails on browser JavaScript
errors, and the encoder checks that the result is animated and has the expected
size and duration. The media is not regenerated by CI.
